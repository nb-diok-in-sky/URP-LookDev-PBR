# 测试环境

文章里的效果图都在下面这套固定的光照和后处理下截取，仿照虚幻引擎的默认设置（没有路径追踪）。

## 光照

| 项 | 值 |
|---|---|
| HDRI | Poly Haven `studio_small_09`，4K .hdr（CC0），导入为 Cubemap |
| HDRI 旋转 / 曝光 | 0° / 1 |
| 环境光 | 天空球谐（SH），强度 1 |
| 反射 | 反射探针按当前天空烘焙，512，只拍天空不拍物体 |
| 太阳 | 平行光，强度 2，白色，俯角 45°、偏航 30°，软阴影（高质量） |
| 阴影 | 主光阴影贴图 4096，4 级级联，阴影距离 40 m |

## 后处理（Volume）

| 项 | 值 |
|---|---|
| 色调映射 | ACES |
| Bloom | 阈值 1，强度 0.3，散射 0.65，高质量过滤 |
| 暗角 | 强度 0.2，平滑 0.4 |
| 曝光补偿 | 0 EV（URP 没有自动曝光） |
| SSAO | 强度 0.5，半径 0.25，来源：深度法线，直接光强度 0.25 |
| 抗锯齿 | MSAA 4× + SMAA（高） |
| HDR 颜色缓冲 | 64 位 |
